## About Cyber Legends

**Cyber Legends** brings together offensive security, digital investigations and secure AI engineering. Our focus is practical: understand exposure, investigate with evidence, and build systems that people can trust.

We work across cybersecurity assessments, digital forensics projects, AI application development and location-aware security. Engagements are tailored to the environment, business objectives and agreed scope.

## Services & solutions

| Practice | Scope | Typical deliverables |
| :--- | :--- | :--- |
| **Advanced penetration testing** | Web applications, APIs, mobile applications, networks, cloud environments and identity systems; business-logic testing and scoped adversary simulation. | Validated findings, attack-path analysis, prioritized remediation and retest results. |
| **Cybersecurity engineering** | Security architecture reviews, configuration hardening, detection engineering, SOC workflows and incident-response readiness. | Gap assessments, hardening recommendations, detection use cases and response playbooks. |
| **Digital forensics & incident response** | Endpoint and disk analysis, memory forensics, log correlation, timeline reconstruction and incident triage within authorized investigations. | Evidence inventories, integrity hashes, chain-of-custody records and findings with clearly stated limitations. |

| **AI & LLM security** | Prompt-injection testing, sensitive-data exposure reviews, RAG access-control testing, agent tool-permission reviews and model abuse assessments. | Threat models, reproducible evaluation cases, risk findings and guardrail recommendations. |
| **Geofencing & location-aware security** | Virtual boundary design, consent-based asset and fleet monitoring, entry/exit alerts, geospatial dashboards and location-aware policy integrations. | Geofence rules, event workflows, integration designs and privacy-aware retention controls. |

## Project focus

We welcome scoped projects in these areas:

- **Security validation:** application and infrastructure assessments, cloud exposure reviews, and remediation verification.
- **Forensic workflows:** evidence intake, artifact triage, investigation timelines and repeatable reporting.
- **Secure AI systems:** enterprise knowledge assistants, controlled AI agents and security evaluation pipelines.
- **Geospatial solutions:** asset-zone monitoring, boundary event processing and alert dashboards.

These are areas for engagement and development. Public code and release status are documented in the linked repositories.

## How we work

1. **Discover & scope** — Define objectives, assets, authorization, success criteria and data-handling requirements.
2. **Assess or build** — Execute the agreed tests, investigation or implementation with documented methods.
3. **Explain the findings** — Deliver actionable results, supporting evidence, business context and technical recommendations.
4. **Validate & hand over** — Review remediation or acceptance criteria and transfer the documentation needed to maintain the result.

## Responsible by design

Security testing is performed only against explicitly authorized assets within agreed rules of engagement. Investigations prioritize evidence integrity, confidentiality and traceability. AI solutions use least-privilege access, evaluation and human oversight for consequential actions. Geofencing projects account for consent, location accuracy, spoofing risk and data minimization; location alone is not treated as proof of identity.
